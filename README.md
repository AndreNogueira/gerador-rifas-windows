# Gerador de Rifas para Windows

Programa para Windows que gera rifas numeradas a partir de um template do Canva (PDF), com os mesmos 4 passos da versão web: template, algarismos, números e destino.

## Descarregar

Vai à página de **[Releases](../../releases/latest)** e descarrega o **`GeradorRifas.exe`**. Não precisa de instalação: é só abrir.

- Cada release tem o **SHA-256** do ficheiro, para confirmares que o descarregaste inteiro e sem alterações.
- O ficheiro **não está assinado digitalmente**: na primeira vez, o Windows SmartScreen pode avisar. Escolhe **«Mais informações»** e depois **«Executar mesmo assim»**.
- Requisitos: Windows 10 ou 11, 64 bits.

## Versão web

Também podes usar a versão web, sem instalar nada: <https://gerador-rifas.onrender.com>
